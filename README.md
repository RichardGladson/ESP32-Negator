# ESP32 Negator - Wi-Fi beacon spammer

Firmware for ESP32 module  
Educational Wi-Fi beacon spammer  

**For educational and authorized testing only.**

## Feartures
Operates on **2.4Ghz** frequency only  

## Hardware
* ESP32 WROOM
* Constant power supply (Micro USB/USB-C)

## Building
Directly flash the code onto the ESP32 module. No libraries are needed.
 ### If the code doesn't work
